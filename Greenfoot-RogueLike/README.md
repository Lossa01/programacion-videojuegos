# Greenfoot RogueLike

Base del rogue-like en Greenfoot (guía del profe). Sin imágenes externas, todo se dibuja por código en FabricaImagenes.

## Para abrirlo

1. New Project en Greenfoot con este nombre, borrar las clases de ejemplo que trae.
2. Pegar los .java de esta carpeta ahí adentro.
3. Compile, botón derecho en JuegoWorld -> new JuegoWorld(), Run.

WASD mueve, espacio dispara.
